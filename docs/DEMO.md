# Seven-minute demo

1. **Credit Overview (45 seconds):** identify the 12 lending products, distinguish requested credit from sanctioned credit, filter the actual synthetic portfolio. Numbers derive from stored applications.
2. **Source evidence (60 seconds):** open Aarav Precision Components, Documents, source PDF, and a reviewed fact. Show the original source and the correction trail.
3. **Financial analysis (45 seconds):** show DSCR/current ratio and the explicit formulas. Open a working-capital case to show indicative borrowing base and transaction review.
4. **Live assessment (60 seconds, queue earlier):** run local Qwen on a case. Show the actual model, recommendation, policy results and uncalibrated confidence label. Existing completed results are prior real runs, not canned answers.
5. **Configurable policy (90 seconds):** add a rule requiring statement coverage of at least 9 months. Save, test all cases and inspect the new blockers. Publish using the administrator's explicit reason. Prior appraisals remain unchanged.
6. **Administrator override (60 seconds):** open a blocked application, click Override, approve with a written rationale. Show the override marker and History; the failed checks still exist.
7. **Retail pricing and bureau entry (60 seconds):** open Loan Products & Pricing, preview a car-loan repayment calculation, then open a retail application and record a manual bureau report. Explain the manual provenance marker and Roopya onboarding status.
8. **Controls and next steps (60 seconds):** audit register, local role preview, PostgreSQL tenant isolation, Gemini/WorkOS configuration status. Explain the production work listed in README.

All borrower figures and sample policies are synthetic. Do not present local-model confidence as default risk. Do not imply identity or document authenticity is verified by extraction.
