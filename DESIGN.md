# Ledger design system

## Direction
THESIS: A credit officer should move from portfolio totals to underlying evidence without losing context.
OWN-WORLD: A financial ledger and credit committee working file. Approved navy/light finance workbench overrides unrelated concept directions (seed ea3a453b).
STORY: Portfolio overview → exception attention → application → source facts → appraisal → accountable decision.
FIRST VIEWPORT: Fixed navy navigation, a restrained financial totals strip, stage-value chart, exception queue, dense application ledger.
FORM: Manrope variable; tabular financial figures; light work surfaces, thin separators, compact controls; no decorative imagery.

## Behaviors
Search and product/status/branch filters persist when opening cases. Every metric derives from stored synthetic records. Forms expose errors without discarding values. Overrides use a focused, keyboard-trapped modal and remain visibly labeled. Input and model states are explicit.

## Accessibility
Visible focus, named icon buttons, status text alongside color, table headers, keyboard-accessible record links, reduced-motion support. Dense numeric tables retain horizontal scrolling on narrow screens.
